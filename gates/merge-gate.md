# 合并门

本门只用于分片 >= 2 的保留总任务实例：合并已 Seal 的子任务分支并解决冲突之后，审
合并引入的变更与组合产生的跨切片结果。不重审各切片本地内容——那归各切片门；本
门的范围是合并与整体。

审查合并引入的变更：冲突解决是否正确、集成修复是否合理、跨切片接缝是否完整衔接。
审查组合产生的跨切片架构回归：模块边界、依赖方向、耦合偏移是否符合整体设计，组合
是否引入不合理的耦合或职责漂移。审查合并整体相对完整需求的比例与复杂度：是否覆盖
了完整需求的每一部分、是否存在超出需求范围的过度设计。

你有权查看各分片 worktree 的变更与主线总变更（base→merged）。各分片 worktree 在本
门审查完成前保留，供你查看；如需要其位置，向 host 索取。切片与合并验证覆盖
Git/SVN/P4：隔离映射为对应 VCS 的工作副本/客户端工作区，合并映射为对应 VCS 的合并
/集成，不声明仅 Git。
