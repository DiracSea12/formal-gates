# C3 替换单元合同：规范化序列化与内容摘要（G1a 第三项）

基线为 C2（候选 `87895e4`，记录提交 `8ac722a`，准入已放行）。

## 职责边界

**做**：把一个已解析的 JSON 值编码为**规范字节**，使其与迁移前 Python 侧 `canonical` 的输出逐字节相同；并提供该字节的 sha256。

**不做**：不读文件、不写文件、不读时钟或随机数；不判断值属于哪个证据族；不改变字节格式。

## 输入与输出

| 项 | 内容 |
| --- | --- |
| 输入 | `value`：任意 JSON 值 |
| 输出 | 规范字节（经桥接以文本承载，Python 侧 `.encode()` 还原） |

桥接操作：

| 操作 | 载荷 | 返回 |
| --- | --- | --- |
| `canonical` | `{"value": <json>}` | `{"canonical": "<规范文本>"}` |
| `digest` | `{"value": <json>}` | `{"digest": "<64 hex>"}` |

## 格式合同（唯一权威在 Go）

必须复现 Python `json.dumps(value, ensure_ascii=False, sort_keys=True, separators=(",", ":"))` 的字节：

| 方面 | 规则 |
| --- | --- |
| 对象键 | 按 Unicode 码位升序（UTF-8 字节序等价） |
| 分隔符 | `,` 与 `:`，无空格 |
| 字符串 | 转义 `"` `\`；`\b \f \n \r \t` 用短转义；其余 < 0x20 用 `\u00xx` 小写；**非 ASCII 原样输出 UTF-8**（`ensure_ascii=False`）；`/` 不转义 |
| 整数 | 十进制，无前导零；任意精度（`-0` → `0`） |
| 浮点 | Python `repr(float)` 规则：十进制定点表示的条件是 `-4 <= 十进制指数 < 16`，定点形式至少保留一位小数；否则科学计数法，尾数 `d[.ddd]`、指数 `e` + 符号 + **至少两位** |
| `null`/`true`/`false` | 小写字面量 |

浮点是与 Go 默认格式化差异最大的一项：`strconv.FormatFloat` 的默认定点/指数阈值与 Python 不同，指数位数也不同，必须自定义。

## 关键边界：桥接信封不是规范化的第二实现

`Bridge.call` 目前用 `canonical` 序列化自己的信封，因此把 `canonical` 指向桥接会**无限递归**。

处置：信封改用**明确的传输编码**（`ensure_ascii=False` + 紧凑分隔符，**不排序**），只要求"是 Go `StrictDecode` 能接受的合法 JSON"。它不是内容寻址格式，也不承载任何摘要语义。保留 `ensure_ascii=False` 是为了不改变既有行为：孤立代理项在信封层仍以 `UnicodeEncodeError` **响亮失败**，而不是被静默替换。

因此 Python 侧不再存在规范化格式的第二份实现；`canonical`/`digest` 的字节权威唯一在 Go。

## 受影响调用方

约 20 个调用点：`infra`（`atomic`、`Store.put`/`event`、`verify_process`）、`job`、`handover`、`workers`、`retention`（归档清单）、`feedback`（比较材料）、`native_zcode`（模型标识）、`graph`（操作 ID）。

`digest` 由 Go 一并拥有，Python 侧只做转发。

## 不变量

1. **逐字节等价**：同一值在 Go 与迁移前 Python 实现下的规范字节相同。这是本单元的核心验收条款。
2. 既有摘要不被改变：任何已存工件引用、操作 ID、证据摘要在新候选下重算必须相同。
3. 桥接失败形状与退出码不变。
4. `LONE-SURROGATE-ESCAPE` 与 `LONE-SURROGATE-LITERAL` 两处已登记差异的行为不变。

## 必需用例

| 用例 | 判据 |
| --- | --- |
| 空对象、空数组、空字符串 | 字节相同 |
| 键排序（含大写、Unicode、空键） | 字节相同 |
| 整数（大整数、负零） | 字节相同 |
| 浮点边界（`1e15`/`1e16`/`1e21`、`1e-4`/`1e-5`、`-0.0`、次正规数 `5e-324`、最大有限值） | 字节相同 |
| 随机浮点（跨多个数量级） | 字节相同 |
| 字符串转义（引号、反斜杠、控制字符、`<`/`&`、U+2028/9） | 字节相同 |
| Unicode（非 BMP、组合字符、RTL、Unicode 键） | 字节相同 |
| 随机嵌套结构 | 字节相同 |

样本量：不少于 400 个，其中随机生成部分占多数，且包含固定种子以便复现。

## 适用宿主

纯计算，不涉及宿主协议、进程、权限或工具继承，不需要原生定向验收。

## 已测量的开销

`canonical`/`digest` 是调用最频繁的原语（每次事件追加、每次原子写、每次工件入存储）。跨进程约 6 ms/次（C2 实测同类原语）。本单元须记录对 fixture 流程实际耗时的影响。
