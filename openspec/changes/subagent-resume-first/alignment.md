# Requirements Alignment

Date: 2026-08-02
Status: confirmed

## RQ-3-1 - 续跑优先（所有受支持宿主）

任何受支持宿主（Claude Code / Codex / Cursor）上，被中断且未产出结果的子代理派发，
若该宿主提供续用机制，SHALL 优先恢复原代理继续完成同一次派发，不首先重开新派发 + 新
代理。

## RQ-3-2 - 续用不可用时回退重开

仅当续用不可用（宿主不支持续用、恢复失败、或生命周期无法认证续用完成）时，SHALL 才
将原派发标 STALE 并重开新派发 + 新零上下文代理。

## RQ-3-3 - 续用完成可生命周期认证

续用完成的派发 SHALL 能经生命周期校验认证（start 事件 + 续用后的 stop 事件成对）。

## RQ-3-4 - 独立性可审计

同一派发的续用 SHALL 保持同一身份、同一结果映射（一次审查、一个身份），不因续用而
模糊审计轨迹；不同派发之间仍不共享身份。

## RQ-3-5 - 边界

本变更 SHALL 不对续用不可用的宿主或攻击式输入加防御；续用不可用即按 RQ-3-2 回退。
