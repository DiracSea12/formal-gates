# 验证语义判断

逐项判断当前签发职责，依据原需求、用例、原始结果与历史证据。

- 发现裁决：核范围、正常使用复现、因果、分类与有效严重度，保留真实 P0/P1。执行 FAIL 本身无严重度。NEW 表示新根因，SAME_AS 关联同根因候选，DISMISSED 须有实际范围/证据依据。既有问题的原发现和裁决历史用于核根因，不能当新待裁决项。
- 执行范围：说明候选变化影响，选择额外受影响的批准用例；必跑项由程序合并。其余项须有真实未受影响的原 PASS，不能继承 FAIL 或缺失证据。
- 门影响：只依据该门原 PASS 与本次原生范围判断 INHERIT/RERUN，给独立因果理由。QA 内容不作门影响或门审结论依据。
- 可选建议：结合原用例、审批与确认范围选择 ACCEPT/DEFER/DECLINE，给具体理由。采纳改变共同路径、可执行性或验收含义时选择全部受影响用例；真实验收缺口不能当可选建议延期。

语义选择、关联序号与输出格式以注入 schema 为准，本职责不授权用户决定。
