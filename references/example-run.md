# 正式流程示例

需求：“给 tdo 增加归档命令，把已完成任务移入归档，并能查看归档列表。”
本例说明用户可见结果，不是模型编排步骤；调用参数见[公共合同](formal-flow.md)。

主代理整理需求、方案、验收与来源，程序预检分配新条目身份并返回完整材料与 revision。用户明确确认后，原 candidate 进入 start；执行行为由所选配置的启用节点决定。
drive 自动消费独立审查、计划与路线的当前职责，在需要用户处置时返回原 Ask。模型只完成原角色的语义任务或转交用户决定。
开发/QA/门的派发、隔离、原生执行、冻结、修复与继承由程序推进；每次只报告程序原证据支持的结果。最终完成以原候选的 promotion、清理与 Seal 证据为准。中断仍用原 run 的 drive，不能据示例手排任务或重建收据。
